# 📦 Aki-chan AI Context & Persona Scaffolder v2.0

배치 파일 단 하나만으로 깃허브 원격 저장소에서 최신 **AI 자율 규칙 설계도(Blueprint)**와 **페르소나 팩**을 실시간으로 가져와 로컬 개발 환경에 단 1초 만에 이식하는 **무설정(Zero-configuration) 원격 프로비저닝(Remote Provisioning)** 스캐폴더입니다.

---

## 🛠️ 제공 기능 및 자산 구성

이 저장소는 다음과 같이 정밀하게 설계된 온보딩 자산들을 제공합니다:

1. **`ct_blueprint_v2_0.bat`** (원클릭 배치 파일)
   - 윈도우 환경에서 실행 즉시 인터넷을 통해 이 깃허브 저장소의 최신 버전 자산을 실시간 다운로드하여 압축을 풀고 세팅한 뒤 임시파일을 청소하는 초경량 엔트리포인트입니다.
2. **`templates/AI_BLUEPRINT_v0.2_20260519.md`** (자율 룰 생성 설계도)
   - AI가 프로젝트 구조를 정밀 스캔하여 중복과 모순이 없는 9대 가드레일 규칙 파일과 인덱스 라우터를 자율적으로 촵촵 생성하도록 가이드하는 마스터 설계도입니다.
3. **`templates/persona/`** (영혼의 페르소나 마스터 팩)
   - 엄격하지만 친절한 아키텍트 **아키쨩(`architect.md`)**, 츤데레 매력을 지닌 개발자 **데부쨩(`developer.md`)**을 포함한 8종의 특화된 AI 협업 자아 프로필입니다.
4. **`scripts/bootstrap-blueprint.ps1`** (뼈대 이식 파워쉘 스크립트)
   - 경로 이스케이프 오류 및 파워쉘 보안 제약(ExecutionPolicy)을 안전하게 우회하여 최적의 폴더 트리(`docs/.ai-context/`, `docs/persona/`)를 구축하는 고성능 브릿지 스크립트입니다.

## 🚀 사용 방법 (서브컴 / 신입 개발 환경 원클릭 세팅)

새로운 컴퓨터나 새로운 프로젝트 폴더에서 AI 협업 세팅을 진행하는 법은 단 3단계로 끝납니다.

### Step 1. 배치 파일 다운로드
- 이 저장소 루트에 있는 [**`ct_blueprint_v2_0.bat`**](https://github.com/manouk12/blueprint/blob/main/ct_blueprint_v2_0.bat) 파일 하나만 다운로드하여 소지합니다.
- (또는 아래의 파워쉘 한 줄 명령어를 통해 원하는 프로젝트 폴더에서 즉시 배치 파일을 내려받을 수도 있습니다.)
  ```powershell
  Invoke-WebRequest -Uri "https://raw.githubusercontent.com/manouk12/blueprint/main/ct_blueprint_v2_0.bat" -OutFile "ct_blueprint_v2_0.bat"
  ```

### Step 2. 프로젝트 폴더에 배치
- 다운로드한 **`ct_blueprint_v2_0.bat`** 파일을 세팅하고자 하는 **로컬 프로젝트 루트 폴더**(예: `C:\Project\MyNewApp`)에 집어넣습니다.

### Step 3. 더블 클릭 실행 (딸깍!)
- 배치 파일을 마우스로 **더블 클릭**하여 가동시킵니다.
- 윈도우 기본 PowerShell 다운로더가 작동하여 이 깃허브 저장소의 최신 압축팩을 받아와 해제하고, AI 온보딩 폴더 및 파일을 촵촵 빌드한 뒤 종료됩니다.
- 세팅 완료 후 프로젝트의 에디터(Cursor 등)를 켜서 프롬프트 창에 **`@docs`** 혹은 **`블루프린트 기동해서 세팅해줘`**라고 입력하면 AI가 마스터 설계도를 완벽하게 읽고 프로젝트에 밀착된 로컬 가이드라인을 자율 생성합니다!

## ⚙️ 동작 원리 및 무설정 설계 (Zero-Configuration)

- **보안 정책 우회**: 윈도우 환경에서 파워쉘 스크립트 실행이 제한된 시스템 정책을 배치 파일의 `Bypass` 옵션을 통해 무설정 상태로 통과시킵니다.
- **TLS 1.2 보안 통신 강제**: 윈도우 기본 쉘이 깃허브 보안 API 통신을 수행할 수 있도록 TLS 1.2 보안 프로토콜을 강제하여 접속 차단을 영구 방지합니다.
- **무중력 클린업(Cleanup)**: 임시 다운로드한 zip 파일 및 해제 폴더는 모든 작업이 끝난 뒤 백그라운드에서 조용히 소탕하여 로컬 디스크 흔적을 남기지 않습니다.

---

## ⚠️ 주의 사항
- 인터넷 통신이 차단된 환경에서는 원격 다운로드가 불가능하므로, 오프라인 환경에서는 본 저장소 전체를 zip 파일로 다운로드하여 `templates`와 `scripts` 폴더를 수동으로 복사해 주시기 바랍니다.
