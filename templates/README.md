# 📦 Harness AI Context Bootstrapper 사용 설명서

이 패키지는 신규 프로젝트 혹은 다른 개발 환경(서브 컴퓨터 등)에서 단 한 번의 조작으로 **AI 협업 컨텍스트 팩**을 구축하고, **개발 환경 및 AI 뷰어 서버**를 통합 구동하기 위해 제작되었습니다.

---

## 🛠️ 제공 기능 및 파일 구성

본 패키지는 다음과 같이 구성되어 있습니다:
- **`딸깍_촵촵_온보딩.bat`**: 환경 세팅 및 기동을 일괄 수행하는 원클릭 배치 파일
- **`templates/AI_BLUEPRINT_v0.2_20260519.md`**: AI가 프로젝트 환경을 분석하여 맞춤형 규칙 문서들을 자동 생성하도록 유도하는 마스터 블루프린트 설계도
- **`templates/persona/`**: 아키텍트(아키쨩), 디벨로퍼(데부쨩) 등 협업에 필요한 핵심 페르소나 설정 마크다운 파일 모음

---

## 🚀 사용 방법 (서브컴/신규 환경 적용)

다른 컴퓨터 혹은 새 프로젝트에 본 설정을 이식하고 실행하는 방법은 매우 간단합니다.

1. **파일 복사**
   - 본 프로젝트의 최상단 폴더 전체를 압축하거나 복사하여, 새로 실행하고자 하는 컴퓨터의 대상 디렉토리에 붙여넣습니다.

2. **배치 파일 실행 (`딸깍` 더블 클릭)**
   - 프로젝트 폴더 내에 위치한 **`딸깍_촵촵_온보딩.bat`** 파일을 마우스로 **더블 클릭**하여 실행합니다.
   - 배치 파일이 실행되면 백그라운드에서 다음 작업들이 자동으로 수행됩니다:
     - 프론트엔드 및 백엔드 개발에 필요한 패키지(`npm install`) 자동 설치
     - 로컬 데이터베이스 스키마 및 마이그레이션 자동 수행
     - 소중한 페르소나 파일들 및 블루프린트 설계도를 프로젝트의 `docs/` 하위로 안전하게 배포
     - **개발 서버 3개 동시 구동**: 백엔드(5000포트), 프론트엔드(3000포트), 아키쨩 인터랙티브 뷰어(4000포트)

3. **작동 및 확인**
   - 세팅이 정상 완료되면 웹 브라우저(크롬 등)가 자동으로 켜지며 **프론트엔드 화면(http://localhost:3000)**과 **아키쨩 산출물 뷰어(http://localhost:4000)** 탭이 점등됩니다.
   - 뷰어 웹 화면을 통해 실시간으로 생성된 AI 가이드라인 규칙과 페르소나 설정을 미려하게 열람하고 에디터로 수정하실 수 있습니다.

---

## ⚠️ 주의 사항 및 팁
- 윈도우 환경의 보안 정책(파워쉘 실행 제한)을 우회하도록 구성되어 있으므로, 반드시 `.bat` 파일을 더블 클릭하여 실행하는 것을 권장합니다.
- 복사 과정 중 기존 `docs/` 내의 주요 문서가 유실되지 않도록 안전 가드레일이 내장되어 있습니다.
